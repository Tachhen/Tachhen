##  What I'm Building

**Event-Driven Order Processing System**  
Building an asynchronous order-processing platform using **Spring Boot, PostgreSQL, Docker, and Apache Kafka**.

Orders are published as events and processed asynchronously by independent consumers for **payment, inventory, shipping, and notifications**, with a focus on reliability, retries, and idempotency.

**Real-Time Chat Application**  
Building a full-stack campus communication platform with **Spring Boot, Spring Security, JWT, WebSockets/STOMP, React, and PostgreSQL/MySQL**.

The application supports real-time messaging and demonstrates how frontend clients communicate with backend services and exchange data through APIs and WebSockets.

 **Autonomous AI Software Engineer**  
Building an AI coding agent capable of understanding software tasks, inspecting repositories, modifying code, running tests, and iteratively fixing problems.

An asynchronous order-processing system built around **Spring Boot and Apache Kafka**.

**Order → Kafka → Payment / Inventory / Shipping / Notification**

The project explores real-world distributed-system concepts including:

- Apache Kafka
- Event-driven architecture
- Asynchronous processing
- Producer / consumer architecture
- Consumer groups
- Retry handling
- Idempotency
- PostgreSQL
- Docker
- Spring Kafka
